What KubeFix Validates & Fixes

  • Syntax & Tabs: Replaces forbidden tab characters, fixes broken indentations and formatting.
  • Deprecated APIs: Automatically updates legacy extensions/v1beta1, apps/v1beta1, networking.k8s.io/v1beta1 to modern v1 APIs.
  • Workload Selectors: Injects or synchronizes spec.selector.matchLabels matching pod template labels.
  • Ingress v1 Migration: Upgrades old serviceName/servicePort backend structure to modern backend.service.name and injects pathType: Prefix.
  • Security Hardening: Recommends removing privileged: true, setting runAsNonRoot: true, and applying baseline seccomp profiles.
  • Resource Quotas: Auto-injects standard baseline CPU and memory requests & limits to avoid noisy neighbors.
  • Secrets: Detects unencoded plaintext strings in Secret data and Base64 encodes them.
  • Privacy Guarantee: All processing is done 100% client-side in your web browser. No manifests or credentials ever leave your machine.
